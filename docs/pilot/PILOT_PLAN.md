# Decision Canvas 小規模試行 相談票

> 目的は、ダミーデータの3分デモと試行案について意見をいただくことです。この相談だけで、会社導入、本番データ利用、公開、他の従業員への利用指示は開始しません。実施する場合は別途正式な承認を得ます。

## 相談内容

Decision Canvasは、業務情報を7分類で整理し、AIまたは端末内ルールが問題・課題候補を作り、担当者が根拠を確認して最終判断するローカルアプリです。デモ後、`デモで終了 / 修正して再相談 / 正式な試行申請を準備 / 中止`のどれが妥当か意見をいただきたいです。

## 提案範囲

| 項目 | 提案内容 |
|---|---|
| 対象 | `[対象業務を1つ記入]` |
| 場所・利用者 | 承認された1拠点・1〜2人 |
| 件数・期間 | 5〜10件・2週間 |
| 目的 | 情報整理と問題・課題設定の時間、修正量、判断しやすさを確認 |
| 方式 | 承認端末でローカル利用。共有URL・外部公開なし |
| 最終判断 | 指定担当者が毎回、採用・保留・却下と理由を記録 |

以上は提案値であり、承認済み計画や実績ではありません。

## データ・外部送信

初回デモと事前評価は、実在の会社・顧客・従業員・案件を元にしない完全な架空情報だけを使います。顧客名、連絡先、注文番号、従業員情報、認証情報、社内機密、無断の社内画面は入力しません。

OpenAI APIを使う場合、ボタンを押した時だけ対象業務、目的、成功条件、制約、判断材料が送られます。案件名、決定者、正式判断履歴は送りません。会社情報を扱う段階では、データ分類、送信可否、契約、保存条件、APIアカウント、費用負担を別途承認します。

## 測定項目

- 1件あたりの判断時間、候補の人間修正量、根拠不足を正しく停止できた件数
- 判断しやすさ（1〜5）、事実と異なる候補・誤解を招く候補の件数
- API利用時のトークンと概算費用、対象業務で合意した指標`[確認時間・追加確認件数・記録率など]`

効果は実測前に断定せず、同じ定義、対象期間、件数で試行前後を比べます。

## 即時停止条件

- 個人情報、顧客情報、認証情報、未承認の機密情報を入力・送信した
- 対象、利用者、件数、期間、費用上限など承認範囲を超えた
- AI候補を人間が確認せず、業務指示や正式判断として使おうとした
- 保存失敗、復元不能、誤共有、端末紛失、不正アクセスの疑いがある
- 重大な事実誤認や業務影響が生じた、または承認者から停止指示があった
