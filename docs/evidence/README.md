## 証跡の性質

- すべて架空データです。実在する顧客・会社・担当者の情報は含みません。
- 2026-08-26 にローカルアプリの完成レポート画面を読み取り、表示内容を転記しました。
- JSONはアプリのバックアップ形式ではなく、レビューしやすい検証証跡スナップショットです。アプリへ復元する用途には使いません。
- AI出力は下書きであり、採否、最終問題文、最終課題文、判断理由は人間が確定した記録です。
- 実行固有のResponse IDは公開版から除去しています。モデル表示とトークン数は、実行時に作成者が画面で目視した参考記録であり、第三者が独立再検証できる証明ではありません。再読込後の由来はアプリ上でも未検証として扱います。
